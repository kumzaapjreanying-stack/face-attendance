# Face Recognition Attendance System (ระบบเช็คชื่อด้วยใบหน้า)

ระบบเช็คชื่อด้วยใบหน้าแบบ Kiosk Mode ผ่านเว็บแคมและเว็บเบราว์เซอร์ พร้อมเชื่อมต่อบันทึกข้อมูลลง Google Sheets อัตโนมัติ

## 🌟 คุณสมบัติเด่น (Features)
- 📸 **สแกนเช็คชื่อแบบ Real-time:** ตรวจจับใบหน้าและคำนวณเวกเตอร์ใบหน้าด้วย `face-api.js` (TensorFlow.js)
- ⏱️ **ยืนยันด้วยการค้าง 2 วินาที:** ป้องกันการเดินผ่านโดยไม่ตั้งใจ พร้อมหลอดสถานะเวลาแบบเรียลไทม์
- 🚫 **ระบบป้องกันการนับซ้ำ (Cooldown):** คนที่เช็คชื่อไปแล้วในวันนั้นจะไม่ถูกบันทึกซ้ำ
- 👤 **ลงทะเบียนคนใหม่ได้ทันที:** มีแท็บลงทะเบียน ถ่ายรูปหน้าตรงบันทึกเข้าเครื่องได้ทันที ไม่ต้องเทรนโมเดลใหม่
- 📊 **แดชบอร์ดสรุปผล:** แสดงจำนวนผู้ลงทะเบียนทั้งหมด, คนที่มาแล้ว, คนที่ยังไม่มา และประวัติเวลา
- 📑 **เชื่อมต่อ Google Sheets:** ส่งข้อมูล (วันที่, เวลา, ชื่อ-สกุล) ไปบันทึกใน Google Sheets ผ่าน Google Apps Script Web App
- 🔊 **Web Audio API:** มีเสียงบี๊บแจ้งเตือนสำเร็จในตัวโดยไม่ต้องโหลดไฟล์เสียงภายนอก

## 📁 โครงสร้างโปรเจกต์
```
lab_02_face/
├── index.html               # หน้าเว็บหลักของระบบ (UI, Scanner, Register, Dashboard)
├── face-api.min.js          # ไลบรารี Face Recognition
├── models/                  # โมเดลตรวจจับและสกัดโครงสร้างใบหน้า (SSD Mobilenet, Landmark 68, Recognition)
├── google_apps_script.js    # โค้ดสำหรับติดตั้งใน Google Apps Script Web App
├── run_server.ps1           # สคริปต์รัน Local Web Server
└── start.bat                # ไฟล์ดับเบิลคลิกเปิดเซิร์ฟเวอร์บน Windows
```

## 🚀 วิธีการใช้งาน
1. ดับเบิลคลิกที่ไฟล์ `start.bat` หรือรันผ่าน PowerShell:
   ```powershell
   powershell -ExecutionPolicy Bypass -File run_server.ps1
   ```
2. เปิดเบราว์เซอร์ไปที่ `http://localhost:8000/`
3. อนุญาตให้ใช้งานกล้องเว็บแคม (Allow Camera Access)
4. ไปที่แท็บ **👤 ลงทะเบียนคนใหม่** เพื่อบันทึกใบหน้าของผู้ใช้งาน
5. สลับไปแท็บ **📸 สแกนเช็คชื่อ** เพื่อเริ่มใช้งาน
